# Input data

The training/evaluation code expects these files in this directory:

- `madrid_train.parquet`
- `amsterdam_data.parquet`

The parquet inputs are not committed. `madrid_train.parquet` exceeds GitHub's 100 MiB per-file limit; the Amsterdam file is kept alongside it as part of the same dataset. Obtain both from the hackathon data source and place them here before running the notebook.
