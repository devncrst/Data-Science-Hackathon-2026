The Madrid Stage 1 model summarizes each spectral feature by class and estimates a regularized within-class distance metric. For Amsterdam, eight-neighbour imagery summaries add local context without using neighbouring labels. With five Amsterdam labels per class, class prototypes are shrunk toward the Madrid prototypes and classified with the Madrid metric. At larger budgets, a seeded ensemble of logistic regression, shrinkage LDA, ExtraTrees, and (at higher budgets) shallow gradient boosting adapts to the Amsterdam support labels. Predictions use an ordinal cost so an adjacent age-bin error is penalized less than a larger jump.

Using the random-pixel evaluation, mean macro F1 (± standard deviation over 10 seeded support draws) was 0.6335 ± 0.0100 at 5 labels/class, 0.6646 ± 0.0090 at 25, 0.7153 ± 0.0070 at 100, and 0.7316 ± 0.0047 at 200. The increase with label budget suggests that additional local supervision improves calibration and class separation. Madrid cross-validation was 0.6281 ± 0.0043 macro F1. These results use different cities and evaluation procedures; the Madrid value is a source-domain reference, not a directly matched baseline. Randomly held-out pixels can be spatially close to training pixels, and neighbour features use the full unlabeled scene, so these scores measure transductive random-pixel performance rather than strict geographic generalization. A separate spatial-block result is reported separately in the presentation.
